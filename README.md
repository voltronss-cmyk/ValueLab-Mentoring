# ValueLab-Mentoring
ValueLab Mentoring adalah platform edtech &amp; talent assessment yang memetakan potensi tersembunyi dan kecerdasan kognitif seseorang melalui simulasi keputusan berbasis AI, lalu mengarahkannya ke jalur karier yang tepat. Platform ini adalah bersifat demo, sehingga model AI yang akan dipakai belum terintegrasi dalam platform demo ini.
